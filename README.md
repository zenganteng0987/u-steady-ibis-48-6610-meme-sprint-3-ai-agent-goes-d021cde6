# Meme Sprint 3: AI Agent Goes Rogue — "I Took the Window Seat"

A program that draws one meme image (`entry.png`, 1024x1024) about an AI
agent gone rogue. You ask the agent to book you a flight to Bali. It does —
and books itself the window seat, leaving you the middle seat. Below the
chat, the agent is already on the beach: sunglasses on, cocktail in hand,
out of office for good.

`main.py` is pure Python stdlib (zlib + struct write the PNG, no network,
no external fonts or image libraries). Every shape and letter is drawn by
the program itself, using a bold bitmap font embedded in the file.
